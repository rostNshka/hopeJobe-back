## 📝 hopeJobe-back
Часть Backend. \
Данный проект разработан исключительно в целях изучения и подкрепления знаний о библиотеках React.
Проект hopeJobe создан поиска работы и подбора персонала. Здесь представлена страница вакансий, избранные вакансии для
соискателя и возможность добавления вакансии работодателем. Так же в проекте представлен личный кабинет.

PS Данная часть проекта будет одной из двух. Вторая часть посвящена беккнд(серверной) разработке.

⚙️Технологии hopeJobe(Backend): \
node.js, \
express, \
JWT, \
JSDoc (Для документации API), \
Prisma, \
PostgresSQL, \
Postman, \
npm 

## ⚙️ Настройка окружения

1) Скопируйте содержимое файла .example.env в .env \
`$ cp .env.example .env`
2) Измените данные \
    а) Для значения PORT установите значение или оставьте по умолчанию \
    б) Для значения JWT_SECRET установите свой ключ для JWT \
    в) Для значения DATABASE_URL установите свои параметры подключения к БД: \
        user - имя пользователя БД \
        password - пароль пользователя БД \
        host - хост БД \
        port - порт БД \
        database - название базы данных \


## 🚀 Использование:
Требования: Для установки и запуска проекта, необходим NodeJS v8+.

Установка зависимостей
Для установки зависимостей, выполните команду: \
`$ npm i`

Запуск генерации Prisma и использование миграций: \
`$ npm run setup`

Запуск приложения: \
`$ npm run dev`

Создание билда, чтобы выполнить production сборку, выполните команду:

`$ npm run build`
